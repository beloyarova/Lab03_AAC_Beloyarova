256 = 00-01-00-00
65536 = 00-00-01-00

1. Почему число 1 занимает 4 байта, хотя для его записи достаточно одного байта?

Потому что размер задаёт тип, а не число (int всегда 4 байта)

2. Что изменяется в байтовом представлении числа 256?

единица переходит во второй байт

3. Почему число 65536 уже требует другого набора байтов?

Потому что каждое умножение на 256 сдвигает байт влево

BitConverter.IsLittleEndian = True
78-56-34-12
Потому что компьютеры с архитектурой x86/x64 обычно используют little endian, то есть младший байт хранится первым

ABC = 41-42-43
Привет = D0-9F-D1-80-D0-B8-D0-B2-D0-B5-D1-82

Почему количество символов и количество байтов может отличаться?

Потому что количество символов и количество байт - это не одно и тоже.

english A: 41
russian А: D0-90

Почему для обратного преобразования нужно снова указать UTF-8?

Потому что байты на хранят информацию о кодировке
